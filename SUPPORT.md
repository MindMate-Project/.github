# Support

## How to Get Help

Before opening a support request, please check the resources below — your question may already be answered.

---

## 📚 Documentation

- **Backend API** — Interactive docs at [https://alzaheimer-backend.onrender.com/api-docs/](https://alzaheimer-backend.onrender.com/api-docs/)
- **Backend README** — [Setup, structure, and API overview](https://github.com/MindMate-Project/Backend#readme)
- **Web App README** — [Local development instructions](https://github.com/MindMate-Project/alzaheimer-web#readme)
- **AI Service README** — [Dockerfile & requirements](https://github.com/MindMate-Project/AI#readme)

---

## 🐛 Reporting Bugs

If you have found a bug, please open an issue in the relevant repository using the **Bug Report** template:

- [Backend issues](https://github.com/MindMate-Project/Backend/issues/new/choose)
- [Web App issues](https://github.com/MindMate-Project/alzaheimer-web/issues/new/choose)
- [AI issues](https://github.com/MindMate-Project/AI/issues/new/choose)

---

## 💡 Feature Requests

Have an idea? Open a **Feature Request** issue in the most relevant repository. See the list above.

---

## 🔒 Security Issues

**Do not open a public issue for security vulnerabilities.** Follow our [Security Policy](SECURITY.md) instead.

---

## 💬 Discussions & Questions

For general questions, design discussions, or help getting started, please use [GitHub Discussions](https://github.com/orgs/MindMate-Project/discussions) (if enabled) or open an issue with the appropriate label.

---

## ⏱ Response Times

| Type | Expected Response |
|---|---|
| Security vulnerability | Within 72 hours |
| Bug report | Within 1 week |
| Feature request | Best effort |
| General question | Best effort |
